Willkommen bei Auto Translator

Chinesischer Text wird automatisch ins Englische übersetzt – ohne Klick, kostenlos und direkt auf diesem Gerät. Einmalig ist nur ein kurzer Schritt nötig.

  1. Sprachpakete laden

    Chrome lädt die Sprachpakete Chinesisch → Englisch (vereinfacht und traditionell) und Englisch → Chinesisch einmalig herunter. Das erfordert genau einen Klick. Danach funktioniert alles offline.

    Status: …

  2. Webseiten öffnen wie gewohnt

    Sobald das Sprachpaket bereit ist, werden chinesische Texte auf allen Webseiten von selbst übersetzt. Bereits geöffnete Seiten bitte einmal neu laden. Über das Symbol der Erweiterung lässt sich die Übersetzung jederzeit ganz oder nur für eine einzelne Seite abschalten.

  3. Text in Bildern

    Chinesischer Text in Bildern, etwa auf Produktfotos und Detailbildern in Shops, wird ebenfalls automatisch erkannt und übersetzt; die englische Übersetzung erscheint direkt auf dem Bild. Der Knopf „原文“ am Bild zeigt das Original. Einzelne Bilder lassen sich per Rechtsklick → „Bild übersetzen“ übersetzen. Auch die Texterkennung läuft komplett auf diesem Gerät.

  4. Auf Chinesisch schreiben

    Wer auf einer chinesischen Seite in ein Feld schreibt, etwa eine Nachricht an den Verkäufer oder eine Suche, kann einfach Englisch tippen. Darunter erscheint die chinesische Übersetzung; mit „Einfügen“ oder Strg+Umschalt+Enter wird sie ins Feld übernommen. Der Text bleibt dabei auf diesem Gerät.
