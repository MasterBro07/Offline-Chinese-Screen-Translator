Willkommen bei Auto Translator

Chinesischer Text wird automatisch ins Englische übersetzt – ohne Klick, kostenlos und direkt auf diesem Gerät. Einmalig ist nur ein kurzer Schritt nötig.

  1. Sprachpaket laden

    Chrome lädt das Sprachpaket Chinesisch → Englisch einmalig herunter. Das erfordert genau einen Klick.

    Status: …

  2. Webseiten öffnen wie gewohnt

    Sobald das Sprachpaket bereit ist, werden chinesische Texte auf allen Webseiten von selbst übersetzt. Bereits geöffnete Seiten bitte einmal neu laden. Über das Symbol der Erweiterung lässt sich die Übersetzung jederzeit ganz oder nur für eine einzelne Seite abschalten.

  3. Optional: Desktop-App starten

    Für chinesischen Text in normalen Windows-Programmen die Auto-Translator-App starten. Sie verbindet sich automatisch mit dieser Erweiterung; Chrome muss dabei geöffnet sein.
